# Internet Intelligence Agent

## Purpose

`@irp/internet-intelligence-agent` is an advisory intelligence layer beside the existing IRP network intelligence and decision engines. It consumes canonical measurements and produces evidence-backed diagnoses and bounded recommendations. It does not replace existing network intelligence, routing, gateway, tunnel, failover, policy or safety components.

## Control boundary

```text
Existing probes / Network Intelligence
              |
              v
      Internet Evidence
              |
              v
  Internet Intelligence Agent
       |              |
       |              +--> optional local LLM advisor
       |                         (localhost only)
       v
 deterministic diagnosis
       |
       v
 advisory recommendation
       |
       v
 Existing IRP policy / safety / decision engine
       |
       v
 existing execution + verification
```

The LLM is never an execution authority. A local model may improve classification or explanation, but the deterministic baseline remains available and the existing IRP policy/safety boundary remains authoritative.

## Free/local inference

The package contains no hosted AI dependency and no OpenAI dependency. `OllamaInternetAdvisor` is an optional local adapter using Ollama's localhost HTTP API. If the local model is absent, unavailable, times out, or returns invalid data, the agent falls back to deterministic analysis without failing the network control loop.

The model is configurable rather than hard-coded as a product requirement. A small local model is appropriate for latency-sensitive deployments; the agent should not require GPU hardware.

## Measurement model

The agent does not perform unrestricted Internet scanning. It analyzes measurements produced by IRP's existing probe infrastructure and can be fed targeted observations for DNS, reachability, TCP/TLS/HTTP, latency, packet loss, IPv4/IPv6 and gateway state. This avoids duplicating probe implementations and keeps network activity bounded and auditable.

## Safety invariants

- LLM output is schema-validated and confidence-bounded.
- Invalid or unavailable LLM output is discarded.
- High-confidence deterministic conclusions cannot be overridden by a local model.
- `possible_interference` is explicitly a hypothesis, not proof of filtering or censorship.
- No VPN, circumvention, arbitrary shell command or unrestricted scanning recommendation is generated by the model contract.
- Evidence is sanitized before being supplied to a model.
- History is bounded in memory.
- Recommendations remain advisory until the existing IRP decision/policy/safety pipeline accepts them.

## Integration rule

Existing intelligence and control subsystems must remain authoritative. New consumers should import this package and adapt `InternetEvidence` from the canonical measurement contracts at the integration boundary rather than moving network logic into the Agent package.
