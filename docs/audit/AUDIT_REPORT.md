## 2. Verified defects (reproduced)

| ID  | Finding                                                                                                                                                                                                                                                                                                                        | Evidence                                                                                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | **No migration creates `User`, `Session`, `Token`, `AuditLog`, `Organization`, `Project`, `Workspace`, `Membership`, `Role`, `Permission`, `RolePermission`, `OutboxEvent`, `CacheEntry`.** `schema.prisma` declares them, but the migration chain only creates enums/extensions plus network, notification and intent tables. | Applied all 5 migrations to a fresh PostgreSQL 16; `\dt` listed 7 tables, none of them identity tables. Any repository written against `schema.prisma` would fail on a migrated database. |
| D2  | API identity state is process-local `Map` stores (`users`, `orgs`, `projects`, `workspaces`, `sessions`) in `apps/api/src/index.ts`. Not durable; not shared between instances.                                                                                                                                                | Source at baseline; confirms issue #410.                                                                                                                                                  |
| D3  | `POST /auth/password-reset/request` and `/auth/email-verification/request` returned `{accepted:true}` and did nothing (fake success). Registration set `status: active` immediately.                                                                                                                                           | Source at baseline; confirms issue #412.                                                                                                                                                  |
| D4  | Bootstrap-admin takeover: whoever registered a bootstrap-admin email address first received `platform_admin` without proving mailbox ownership.                                                                                                                                                                                | Source at baseline (`isBootstrapAdminEmail` at registration).                                                                                                                             |
| D5  | Logout did not revoke access tokens: authentication was stateless JWT only, so an access token stayed valid up to 15 minutes after logout.                                                                                                                                                                                     | Source at baseline.                                                                                                                                                                       |
| D6  | The refresh "token" was not bound to the stored session secret; no reuse (theft) detection or family revocation.                                                                                                                                                                                                               | Source at baseline.                                                                                                                                                                       |
| D7  | No tenant isolation: any principal with `organizations:read` listed every organization; projects/workspaces had no ownership filter; a workspace could reference a project of another organization.                                                                                                                            | Source at baseline.                                                                                                                                                                       |
| D8  | Rate limiting was `InMemoryRateLimiter` per process: ineffective across instances. Fastify has no `trustProxy`, so `request.ip` behind a proxy would be the proxy address.                                                                                                                                                     | Source at baseline.                                                                                                                                                                       |
| D9  | `createPrismaClient` without `DATABASE_URL` returns a fake client whose `$queryRaw` answers `[{ok:1}]` for any query. Safe only for health checks; dangerous as a repository backend.                                                                                                                                          | `packages/database/src/index.ts`.                                                                                                                                                         |
| D10 | `PROJECT_STATE.md` names HEAD `9d6c1d5` (2026-10-27) while `main` is `200de48`. Stale evidence.                                                                                                                                                                                                                                | `git ls-remote`.                                                                                                                                                                          |
| D11 | The Linux acceptance test asserts live authority from CAP_NET_ADMIN alone and fails when `ip` is absent; the production behaviour (fail closed) is right, the test assumes a fully provisioned host.                                                                                                                           | Reproduced both ways (fails without `iproute2`, passes with). **Resolved:** the test now branches on `capNetAdmin && ipBinary` and a deterministic empty-`PATH` test asserts the missing-`ip` fallback. |
| D12 | CodeQL: `.github/workflows/codeql.yml` ("CodeQL Advanced") analyses `actions` and `javascript-typescript` only; Swift is not in the matrix. The Default-Setup/Advanced conflict is a repository setting.                                                                                                                       | Workflow file; settings not reachable from the sandbox.                                                                                                                                   |
| D13 | `apps/api/src/unified-product-api.ts` still uses `InMemoryRateLimiter`.                                                                                                                                                                                                                                                        | grep.                                                                                                                                                                                     |
