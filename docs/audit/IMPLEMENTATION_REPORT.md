### Behaviour changes callers must know

- Login requires a verified email (`403 Email verification required` for pending users). New endpoints: `POST /auth/email-verification/confirm`, `POST /auth/email-verification/request` (now takes `{email}`, unauthenticated), `POST /auth/password-reset/confirm`.
- Refresh tokens are opaque (no longer JWTs). Replaying a rotated token revokes the lineage.
- Registration response includes `emailDelivery`.
